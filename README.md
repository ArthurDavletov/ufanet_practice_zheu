# Система ЖЭУ

Проект реализует простую систему для взаимодействия жителей, рабочих и администратора ЖЭУ: новости, заявки, статусы работ, оценки и уведомления.

## Запуск

Нужны Docker и Docker Compose.

```bash
docker compose up --build
```

После запуска будут доступны:

| Сервис | Адрес |
| --- | --- |
| Фронтенд | http://localhost:8080 |
| AuthService | http://localhost:8001 |
| SessionService | http://localhost:8002 |
| TicketsService | http://localhost:8003 |
| NewsService | http://localhost:8004 |
| NotificationService | http://localhost:8005 |

API-документация FastAPI доступна у каждого сервиса по адресу `/docs`:

- http://localhost:8001/docs
- http://localhost:8002/docs
- http://localhost:8003/docs
- http://localhost:8004/docs
- http://localhost:8005/docs

Для остановки контейнеров:

```bash
docker compose down
```

Если нужно удалить локальные данные PostgreSQL и начать с чистой базы:

```bash
docker compose down -v
```

## Тестовые пользователи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Житель | resident | resident123 |
| Рабочий | worker | worker123 |
| Администратор | admin | admin123 |

На странице входа есть быстрые кнопки для входа под этими пользователями.

## Роли

`MINIMAL` - базовая безопасная роль. Она нужна для входа в систему и просмотра общедоступных разделов, например новостей.

`RESIDENT` - житель. Может создавать заявки, смотреть свои заявки, отменять активные заявки, получать уведомления и оценивать выполненные работы.

`WORKER` - рабочий. Видит заявки, фильтрует их по статусу и переводит заявки по допустимым переходам FSM.

`ADMIN` - администратор. Публикует новости, добавляет адреса и назначает пользователям основную роль.

Новые пользователи после регистрации сразу получают роли `MINIMAL` и `RESIDENT`, поэтому администратору не нужно вручную одобрять каждую регистрацию. При назначении роли через админку основная роль заменяется, а не накапливается: пользователь не становится одновременно жителем, рабочим и администратором.
